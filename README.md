# 3D Pythagorean Visualizer

This is basically a 3D pythagorean theorem visualizer i made in Roblox. It takes a point and shows the distance from an origin point using the X Y and Z axis. The red green and blue lines show the individual axis distances and the orange line shows the actual diagonal distance between the two points.

It updates every frame so it works with moving objects like a players humanoidRootPart. I made it to understand better CFrames, they still annoying tho

It also supports multiple points and custom origins so it can be used for testing different things.
